# Wood Contractor Lifecycle

INQUIRY → QUALIFIED → SURVEY_SCHEDULED → SURVEY_DONE → ESTIMATING → QUOTED → NEGOTIATION → WON → DP_RECEIVED → PROCUREMENT → PRODUCTION → QC → DELIVERY_READY → INSTALLATION → HANDOVER → WARRANTY → CLOSED.

Exceptional states: ON_HOLD, LOST, CANCELLED.

Hard gates prevent production without financial release, delivery without passed QC, and closure without accepted handover. These gates are deliberate operational controls, not UI validation.
